
# Git Workflow Documentation

## 1. Repository Initialization
Initialized a local Git repository using git init.

## 2. Main Branch
The main branch contains the stable project version.

## 3. Development Branch
The dev branch is used to integrate development changes.

## 4. Feature Branch
Feature branches are created from dev to work on individual changes.

## 5. Commits
Changes are saved using meaningful commit messages.

## 6. Pull Requests
Pull Requests are used to review and merge feature changes into dev and dev into main.

## 7. Git Tag
A version tag is created to identify a project release.

## 8. Git Ignore
The .gitignore file excludes unnecessary files and sensitive local configuration.

## Conclusion
This workflow demonstrates basic Git version control practices.
