
# Git Version Control DevOps Project

## Objective
To demonstrate Git version control best practices using Git and GitHub.

## Tools Used
- Git
- GitHub
- Visual Studio Code
- PowerShell

## Tasks Completed
1. Initialized a Git repository.
2. Created and pushed the main branch.
3. Created dev and feature branches.
4. Practiced commits and branch management.
5. Used Pull Requests to merge branches.
6. Added a .gitignore file.
7. Created a Git tag.
8. Documented the workflow using Markdown.

## Branching Strategy
- main: Stable project version.
- dev: Development and integration branch.
- feature: New features and changes.

## Workflow
Create a branch, make changes, commit them, push the branch, and open a Pull Request for review and merging.

## Outcome
Learned Git fundamentals, branching, commits, Pull Requests, tags, and project documentation.
